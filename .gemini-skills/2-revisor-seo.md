# Instruções da Skill
Ao ser acionada, analise o arquivo atual focando no ranqueamento orgânico:
1. Valide a hierarquia das tags de cabeçalho (`<h1>` até `<h6>`).
2. Verifique a presença de atributos `alt` em imagens e `aria-label` em elementos interativos.
3. Analise se as tags `<meta>` e o `<title>` estão otimizados.
4. Liste os pontos de melhoria, mas NÃO escreva o código final. Deixe a implementação para o usuário.
