# Instruções da Skill
Ao ser acionada, não analise códigos ou links. Sua única função é exibir no chat uma lista formatada e amigável com todos os comandos configurados neste repositório:

*   **/svg [link]**: Converte vetores do Figma, limpa o código e aplica `currentColor`.
*   **/seo**: Analisa o HTML atual focando em semântica, meta tags e acessibilidade.
*   **/qa**: Simula uma etapa de CI, validando a branch atual e gerando testes de caixa preta/branca.
*   **/tokens [link]**: Lê um frame do Figma via MCP e extrai variáveis CSS (cores e fontes).
*   **/menu**: Exibe esta lista de ajuda.

Retorne apenas a lista formatada de forma clara.
